# CEULAZUR // Personal Portfolio

A multilingual, editorial-style personal portfolio for GitHub Pages.

## Included
- Responsive single-page portfolio
- Portuguese, English and Simplified Chinese (Mandarin) interface
- Language selector with preference saved in the browser
- Custom blue orchid and city imagery in `assets/images/`
- Animated reveal-on-scroll, responsive mobile navigation
- Sections for profile, research, projects, experience, skills and contact

## Stack
HTML5 · CSS3 · Vanilla JavaScript · GitHub Pages

## Preview locally
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Publish
1. Create a **public** GitHub repository named `ceulazur.github.io`.
2. Upload the *contents* of this folder to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After deployment, open `https://ceulazur.github.io`.

## Personalize before publishing
- Check every date and project description.
- Add verified project links, papers and a downloadable CV.
- Confirm the LinkedIn and email URLs.
- Add any approved photos or project screenshots to `assets/images/`.

The website is static, so it does not need a backend or database. All language switching and animation run in the visitor's browser.
